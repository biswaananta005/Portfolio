## 🚀 Quick Start / Local Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/biswaananta005/Portfolio.git
   cd Portfolio
   ```

2. **Run locally**:
   - Open `index.html` directly in your browser, or launch with Python:
     ```bash
     python -m http.server 3000
     ```
   - Access at `http://localhost:3000`
